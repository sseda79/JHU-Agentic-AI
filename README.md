# Agentic AI Certificate Projects

Coursework projects completed as part of the **Certificate Program in Agentic AI** (Johns Hopkins University, delivered via Great Learning), April to August 2026.

These are learning exercises built to apply agentic AI concepts (multi-agent orchestration, RAG, tool calling, state management, human-in-the-loop design). They are not production systems, and were not built or tested to production standards.

## Projects

1. **[DualLens Analytics](./project-1-duallens-analytics)** — RAG-based analysis combining financial data with company AI-initiative research (Course: Prompt Engineering Foundations)
2. **[Autonomous Financial Research Analyst](./project-2-autonomous-financial-analyst)** — Agent that progresses from a reactive LLM to a full tool-using, RAG-enhanced investment research agent (Course: Designing and Building Agentic Systems)
3. **[Senior Mortgage Underwriting System](./project-3-mortgage-underwriting)** — Multi-agent loan underwriting system with PII redaction, bias detection, and policy RAG (Course: Advanced Agentic AI)

## Setup

Each notebook reads API configuration from a local `config.json`, which is intentionally excluded from this repo (see `.gitignore`). Copy `config.example.json` to `config.json` and fill in your own values before running any notebook.
